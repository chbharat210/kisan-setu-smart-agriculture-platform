# Kisan Setu — Smart Agriculture & Agro Advisory

## Run frontend
```bash
cd client
npm install
npm run dev
```

## Run backend
```bash
cd server
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5001
